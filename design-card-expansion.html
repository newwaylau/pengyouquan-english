1.1 经典模式卡牌池标准

炉石传说的标准模式（Standard）核心套装通常包含 ~240 张卡牌，涵盖所有职业（9-10个）加上中立卡。每个职业约 15-20 张职业卡 + 20 张中立卡。一个扩展包（Expansion）通常包含 130-145 张 新卡。当仅设计单一主题扩展时，最低可玩阈值约为 120 张 — 即确保玩家可以构筑出有足够深度的卡组。

4.1 奥秘密码体系

🔐 暗码激活协议（CPP — Cipher Protocol for Secrets）

所有奥秘以 符文序列 形式编码，对手可见但不解其意。每个奥秘对应一个维斯特洛古符文图案，在触发前以 发光符文 展示在英雄头像旁。对手需支付 2 点法力来"解读符文"（类似炉石测奥秘机制），或根据攻击顺序和触发条件反推。奥秘总是从左侧激活，最新奥秘在右侧。

⚔️ 武器系统机制

武器卡装备到英雄武器槽。英雄攻击时消耗 1 点耐久，攻击力代替英雄基础攻击力（基础仍为 0）。耐久归零时武器损毁。部分武器拥有被动特效（装备时持续生效）和攻击特效（英雄攻击后触发）。暗影匕首是唯一具有 潜行 关键词的武器，装备时对手不可见其存在。

  border: 2px solid #475569;           /* 铁灰色边框 */

}

/* ——— 稀有（Rare） ——— */
.border-rare {
  border: 2px solid #3b82f6;           /* 蓝色边框 */
  box-shadow: 0 0 12px rgba(59,130,246,0.3),
              inset 0 0 20px rgba(59,130,246,0.05);
  animation: rareGlow 3s ease-in-out infinite;
}
@keyframes rareGlow {
  0%, 100% {
    box-shadow: 0 0 12px rgba(59,130,246,0.3),
                inset 0 0 20px rgba(59,130,246,0.05);
  }
  50% {
    box-shadow: 0 0 20px rgba(59,130,246,0.5),
                inset 0 0 30px rgba(59,130,246,0.08);
  }
}

/* ——— 史诗（Epic） ——— */
.border-epic {
  border: 2px solid transparent;
  background-clip: padding-box;

.border-epic::before {
  content: '';
  position: absolute;

7.3 稀有度边框参数对照表

稀有度边框类型主色动画效果持续时间粒子
普通 实线 2px #475569 静态 — ❌
稀有 实线 2px + 蓝光 #3b82f6 呼吸式光晕脉冲 3s ❌
史诗 conic-gradient 蒙版边框 #7c3aed ~ #a78bfa 等速旋转渐变 4s ❌
传说 conic-gradient 蒙版边框 + 辉光 #fbbf24 ~ #f59e0b 旋转 + 呼吸辉光 + 粒子上浮 3s + 2s ✅ 8粒子随机

💡 实现要点

1. mask-composite 技巧：史诗和传说边框使用 content-box + mask-composite: xor 实现仅边框渐变，内容区域保持不透明。这是纯 CSS 实现渐变边框的推荐方式。

2. 性能优化：conic-gradient 动画仅旋转 ::before 伪元素，不会触发布局重排（reflow）。粒子使用 translateY 和 opacity 动画，可通过 will-change: transform, opacity 开启 GPU 加速。

3. 可访问性：用户可以通过 @media (prefers-reduced-motion: reduce) 禁用动画，保持静态边框。
