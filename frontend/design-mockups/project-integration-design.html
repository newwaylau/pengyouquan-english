📦 P0：卡牌收集 + 卡册 + 卡组

改动最小，3 天可上线。玩家体验闭环：听写 → 开包 → 看卡 → 组牌

入口在哪

自动把卡插入 user_cards 表，弹窗显示获得了什么稀有度的卡。
修改：PracticePage.tsx（+开包弹窗）
新增：api/cardClient.ts（grantCardPack 调用）
🎴 底部导航新增「卡牌」 P0

🔗 P1：好友挑战 + 装备系统

引入社交元素和策略深度，用到已有的封臣/邀请系统

入口在哪

👫 封臣页 → 好友挑战 P1
在 LeaderboardPage.tsx 的封臣 tab 中，好友列表旁新增「⚔️ 发起对战」按钮。
点击后选择对方卡组 → 发起挑战 → 对方离线时 AI 托管防守。
对战结果通过通知系统推送给对方。
修改：LeaderboardPage.tsx（+挑战按钮）
修改：NotificationController.java（+挑战通知）
🛡️ 卡牌详情 → 装备槽 P1
在卡牌详情弹窗中，新增「装备」区域。显示该随从的 3 个装备槽。
点击空槽 → 列出可用的装备（按 slot 筛选）。
装备通过完成高准确率听写/全收集获得。
修改：CardCollectionPage.tsx（装备 UI）
新增：POST /api/equipment/equip
📊 排行榜 → 对战排名 P1
排行榜新增一个「⚔️ 对战」tab（在现有 今日/本周/本月/狼群 旁）。
显示好友对战胜率/胜场。这是 P1 阶段的简单统计，不是天梯。
修改：LeaderboardPage.tsx（+新 tab）
⚠️ P1 关键依赖

P1 需要一个简陋的对战引擎——玩家 A 发起挑战 → 后端模拟对局（不需要实时 UI）→ 返回结果。
这个引擎在 P0 就应该以 AI vs AI 的形式存在（AI 对战用）。P1 只是把 AI 换成对手的卡组。
引擎可以简单：每回合按费用从高到低出牌，攻击随机目标。不要求聪明。

📋 总结：点哪里进入什么

P0 上完后，用户会看到：

  1. 练习完一集 → 自动弹出「🎊 开包动画」→ 查看新获得的卡
  2. 底部导航新增「🎴 卡牌」→ 点进去看到所有收集的卡
  3. 卡牌页内有「🗃️ 卡组」标签 → 编辑自己的 30 张卡组
  4. 卡牌页底部「⚔️ 匹配对战」按钮 → P2 后才可用，P0 先禁用或跳转提示"即将开放"

P1 上完后，额外：

  1. 封臣页 → 好友列表 → 点击「⚔️ 发起对战」→ 异步 AI 托管对战
  2. 卡牌详情 → 看到装备槽 → 可以给随从穿装备
  3. 排行榜新增「⚔️ 对战」排名

P2 上完后，额外：

  1. 卡牌页「⚔️ 匹配对战」→ 变成可用按钮 → 实时匹配真人 → 完整战场
  2. 排行榜新增「🏆 天梯段位」tab
  3. 对战中打出 ✍️ 卡 → 弹窗要求听写/拼写

P3 上完后，额外：

  1. 封臣页 → ⚔️ 公会战（公会 vs 公会）
  2. 排行榜 → 📺 正在直播（观战）
  3. 卡牌页 → 🏟️ 锦标赛（64 人淘汰赛）
