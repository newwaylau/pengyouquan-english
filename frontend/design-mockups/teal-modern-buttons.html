🎨 设计要点

  • 导航按钮：仅 Hover 时显示背景，Active 态底部 Teal 指示条 + 文字更亮 → 区分清晰
  • Primary：渐变填充 + 阴影 → 视觉重量最重；Hover 上移 1px + 阴影增强 → 浮起感
  • Secondary：透明底 + 细边框 → 轻量感；Hover 时 Teal 边框 + 背景 → 引导视觉流向
  • Chip：药丸形，选中态填充 Teal + 阴影 → 高亮突出
  • 禁用态：统一 opacity 0.30~0.35，所有指针事件禁止 → 系统一致
  • 触摸目标：最小高度 44px（导航）~48px（Primary），满足 WCAG 触控要求
  • 颜色系统：#14b8a6 (Teal) 为主色，#2dd4bf 为浅色渐变，#0d9488 为深色渐变
