🎭 多剧集卡牌对战框架

不绑死任何一部剧——每部剧都是一个可插拔的扩展包，核心框架通用

0. 问题分析

目前的设计把游戏绑死在 GOT 上：

层面当前设计（GOT 绑定）问题
派系史塔克、兰尼斯特、坦格利安新剧（如《老友记》）没有这些派系
卡牌角色艾德·史塔克、詹姆、卓耿DA 有卡劳利家族，老友记有瑞秋莫妮卡，不是同一个宇宙
装备瓦雷利亚钢剑、龙鳞甲DA 没有龙，老友记没有剑
场地君临城、绝境长城DA 的场地是庄园，老友记的场地是中央公园咖啡馆
世界观权游奇幻DA 是 20 世纪初庄园剧，老友记是现代情景喜剧——强行统一风格很奇怪
⚠️ 核心矛盾

如果每部剧都用同一个世界观（GOT），那新剧加入时要么强行改编剧情（DA 角色被塞进维斯特洛），要么每部剧独立一套完全不同的游戏系统（开发量 ×N）。

两种都不可行。 需要的是一个 框架级 的解——所有剧共用一套对战引擎，但每部剧以「内容包」形式提供自己的卡牌、效果、视觉风格。

1. 框架设计：三层架构

卡牌对战系统 = 通用引擎 + 内容层 + 视觉层，每层各司其职

第一层

⚙️ 对战引擎（通用，永不修改）

不变的规则

  • 7 阶段回合制（之前已设计）
  • 法力水晶系统（1→10）
  • 11 个关键词（战吼/亡语/嘲讽/圣盾/冲锋/潜行/法强/抽牌/耐久/考验/派系关联）
  • 装备三槽体系（武器/护甲/宝物）
  • 段位/天梯/赛季
  • 出牌考验机制

不可变的 UI

  • 战场布局（对手→中场→玩家）
  • 手牌区/法力条/操作栏
  • 出牌考验弹窗
  • 回合指示器/计时器
  • 装备/随从交互

第三层

🎨 视觉层（每部剧独立皮肤）

  • 卡牌边框：GOT 用黑金/龙纹，DA 用象牙金/花体，老友记用暖橙/沙发纹理
  • 卡牌背景：每个卡牌使用该剧对应剧照/场景截图作为背景
  • 战场主题：玩家可选择当前启用的剧集皮肤（默认根据卡组主力剧集切换）

视觉层在设计上使用 CSS 变量化，新剧加入 = 新的一组 token 值，不需要改引擎。

每部剧上线时只需填写统一模板，引擎自动解析所有卡牌

💡 关键洞察

卡牌效果不需要和剧情一模一样，只需要让玩家觉得"这很符合那个角色"即可。
比如瑞秋·格林的效果是"复制对手一张手牌"——剧情上她没有这个能力，但玩家会觉得"对，瑞秋是那种能从别人那得到东西的人"。
这种印象派匹配比写实匹配更容易设计出好游戏。

3. 派系系统重设计

派系 = 剧集，但不仅仅是剧集——还有跨剧联动的可能

3.1 派系机制

概念定义示例
基础派系一部剧就是一个派系「权力的游戏」「唐顿庄园」「老友记」
派系纯化 bonus卡组中所有卡牌都来自同一部剧 → 激活特殊效果纯 GOT = 开场抽 2 张
纯 DA = 每回合恢复 1 HP
跨派系 synergy某些剧之间存在关键词联动GOT + DA 的「贵族」属性卡获得加成
中立卡不绑定任何剧集的通用卡牌「基本装备」「通用法术」（所有玩家初始获得）

3.2 卡组构建的可能形态

卡组类型构成优势劣势
纯系卡组全部卡牌来自同一部剧激活派系专属 bonus卡牌选择受限，容易被针对
双系卡组两部剧的卡混合可覆盖更多策略维度无派系 bonus，配合需要磨合
混搭卡组多部剧 + 中立卡卡池最大，灵活应对缺乏主题深度，节奏可能松散
💡 这个设计给了玩家很强的学习动机

想玩纯系卡组？你必须学完这部剧的足够集数才能解锁足够多的卡牌。
想玩双系？你需要学完两部剧。
这不再是"为了学而学"——这是"为了组出我想玩的卡组而去学"。
每加入一部新剧，玩家的卡池战略多了一个维度，旧剧的卡可能因为新剧加入而产生新的配合。

4. 装备系统重设计

装备来源二分：通用装备（所有剧共享） + 剧集专属装备（从该剧内容产出）

4.1 通用装备（初始获得，永久可用）

位置装备效果获取
武器🗡️ 训练木剑+1 ATK，3 耐久初始赠送
武器🗡️ 铁剑+2 ATK，2 耐久20 场对战解锁
护甲🛡️ 布甲+1 HP初始赠送
护甲🛡️ 链甲+2 HP50 场对战解锁
宝物💎 幸运币每 3 回合开始获得 1 临时法力天梯达到黄金

4.2 剧集专属装备（从学习该剧获得）

剧集装备效果获取条件
GOT🗡️ 瓦雷利亚钢剑+3 ATK，2 耐久。史塔克随从 +1 ATKGOT 全收集
🛡️ 龙鳞甲+2 HP，1 护盾。火焰伤害 -1准确率 ≥95% 集
DA🎩 家族印章戒指+1 ATK，回合开始指挥 1 个 1/1 仆人DA 全收集
👗 蕾丝手套+1 HP。你每打出一张法术，装备随从 +1 HP准确率 ≥95% 集
未来剧每部剧 2-3 件专属装备遵循统一模板：稀有 + 史诗各 1-2 件，与该剧主题绑定

4.3 装备的"剧集亲和"概念

每件装备有一个 affinity（亲和） 属性，指明它最适合哪部剧的随从：

  • 瓦雷利亚钢剑 → affinity: GOT → 装备在 GOT 随从上时效果 100%，其他剧随从只有 80%
  • 家族印章戒指 → affinity: DA → 同理
  • 铁剑、链甲 → affinity: 通用 → 任何随从都是 100%

这又给玩家一个动机：想发挥某件装备的最大威力？去学它的来源剧集。

5. 战场设计：去主题化

战场本身不绑定任何剧集——它是一个通用的"竞技场"

桌游竞技场（默认）

深色木质桌面风格，中性的棋子/卡牌布局。
没有城堡、没有龙、没有特定剧集元素。
所有玩家看到的默认战场相同，就像下棋。

主题皮肤（可选）

玩家可在设置中选择战场皮肤：
- 🐉 维斯特洛石板地图
- 🎩 唐顿庄园橡木书房
- ☕ 中央公园咖啡馆沙发区
皮肤不影响游戏功能，纯视觉。

💡 为什么要去主题化

如果战场默认就是维斯特洛，那《唐顿庄园》的玩家会觉得"这游戏是 GOT 专有的"。
通用竞技场 = 所有剧集的玩家都是平等的。
加入新剧时完全不需要改引擎或 UI — 只需要往数据库插入新卡牌数据。

6. 玩家成长路径（多剧集视角）

不是"打通 GOT 再说"，而是"每部剧都是可选的成长树"

📖 学业线（已有）
  • 10 级封号系统（不变）
  • 每日御前挑战（已有）
  • 每部剧有独立的完成度 %
  • 剧集完成度影响：该剧卡牌解锁率、专属装备获取
⚔️ 竞技线（新增）
  • 天梯段位（青铜→王者）
  • 赛季限定卡牌（每赛季 1 张）
  • 卡组多样性奖：鼓励使用不同剧集卡组
  • 巅峰赛：限时指定派系环境（如"本月仅限 DA + GOT"）
📊 新剧上线时会发生什么？

1. 内容团队填写「剧集扩展包模板」→ 生成 20-40 张新卡牌
2. 运行自动测试 → 检查新卡牌是否和现有引擎兼容
3. 部署到 SIT → 新旧卡一起匹配无异常
4. 上线当天玩家可看到新剧内容，开始学习 → 收获新卡牌
5. 新剧上线 2 周后环境稳定 → 如果纯派系 bonus 太强/太弱，调整数值

整个过程不需要改一行引擎代码。只需要：数据 + 测试 + 部署。

🎯 最终设计总结

核心一句话：卡牌对战引擎是中立的，每部剧是可插拔的内容包。

玩家视角：我学 GOT → 拿到 GOT 卡组。我学 DA → 拿到 DA 卡组。我可以纯 GOT 打纯 DA，也可以混搭，也可以和学老友记的人对战。不管对手学的是什么剧，我们对战的是同一套规则。

运营视角：新剧上线 = 新卡包上线。不需要开发新玩法，不需要改代码。内容团队填模板 → 测试 → 上线。

增长视角：玩家为了让卡组更强，会主动去学没看过的剧。这是强于任何推送通知的"内容发现引擎"。

框架的终极形态：剧集扩展包可以做"稀有度分级"——GOT 这种大制作有 40 张卡 + 3 件专属装备，DA 有 30 张 + 2 件，轻量剧有 15-20 张 + 1 件。每部剧的 card_count 与它的内容量成正比，自然地。
