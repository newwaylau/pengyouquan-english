模式一：铁王座竞技场（PVP）
皇室战争的奖杯系统 + 炉石传说的回合制费用对战
🏆 奖杯段位 🔥 实时/异步双模式 📦 赛季宝箱 🏰 公会领地

🎮 两种对战模式

⚡ 实时匹配（炉石式）

双方同时在线，标准炉石回合制。答对出牌，答错送对面费用。5分钟一局。

需要 WebSocket

📡 异步挑战（皇室战争式）

进攻方布阵 → 对方登录应战 → AI按真实数据模拟。对方离线也可打。

纯 REST，P1 可做

⚙️ 回合制对战引擎（炉石核心）

  1. 起始 — 从30张卡组抽3张。每回合+1费上限（起始3费，最高10费），抽1张
  2. 出牌 — 选择手牌 → 系统出该卡对应的英语考题 → 答对=出牌成功，卡牌上场；答错=牌回手，费用不退，对手抽1张
  3. 攻击 — 已上场的随从可攻击。攻击时对手需答防御题，答对减半伤害
  4. 法术/效果 — 法术牌答对直接生效。效果如"抽2张牌""全场打3"等
  5. 胜利 — 击败对手英雄（30血），或10回合后血量高者胜

🏆 奖杯+宝箱系统（皇室战争核心）

🏆 奖杯段位

0杯→青铜→白银→黄金→白金→钻石→传说（1000+杯）。胜+30杯，输-25杯。赛季末结算。

像皇室战争的 trophy road

📦 宝箱系统

每胜一场获得一个宝箱（青铜/白银/黄金）→ 需要练指定数量的句子才能解锁。

像皇室战争的 unlock timer，但用"学习量"代替"时间"

🎁 赛季宝箱

每月赛季末按段位发奖：传说=1传说卡包+5随机卡；白金=1史诗卡包+3随机；青铜=3普通卡。

像皇室战争的 season chest

🏰 公会领地

公会（封臣领地）每周集体贡献比拼。所有成员本周练习总和计入公会战分数。

像皇室战争的 clan wars

杀戮尖塔的Roguelike爬塔 + 英语学习成长
🗺️ 随机地图 🎲 事件抉择 🪙 遗物系统 ⭐ 卡牌升级

🎮 爬塔流程（每局15-25分钟）

  1. 选初始卡组 — 从你的收藏选 10 张牌作为"远征牌组"（不是30张，是精简构筑）
  2. 选择路线 — 像杀戮尖塔一样显示地图节点：🟢战斗 / 🟡事件 / 🔵休息 / 🟣Boss
  3. 战斗节点 — 出一道英语题 → 答对抽卡 + 对敌人造成伤害 → 答错受伤。击败敌人后三选一奖励（新卡/Buff/回血）
  4. 事件节点 — 随机剧情抉择。如"发现一本古籍"→ A)花5分钟精读（得稀有卡）B)快速浏览（得普通卡）
  5. 休息节点 — 回血 30%，或给一张卡牌升级（攻+1/防+1）
  6. Boss战 — 段落听写式终极挑战。全屏长句，逐词填空，答对打断Boss技能

🪙 遗物系统（杀戮尖塔核心）

📜 龙鳞护符

本局所有选择题变为听力题（难度↑但奖励×1.5）

🦅 渡鸦之眼

每场战斗第一次答错不扣血

🔥 龙焰宝珠

答对时对敌方额外造成 2 点伤害

🛡️ 铁王座碎片

每通过一个Boss，回满血

每天一局的轻量Roguelike，碎片时间友好
🎲 随机Boss 🔄 三选一Buff 🏅 全服排行 ⏱️ 5分钟

🎲 随机Boss

每天一个特殊Boss（如"Walder Frey — 背叛者"）带特殊规则：
"本场所有法术牌费用+2""所有随从攻击力减半"

🔄 三选一Buff

每答对 5 题后，3选1 Buff："下3题减时50%""双倍伤害""免费复活一次"

🏅 全服排行

按答对率×难度系数×用时 综合排名。前 100 名获额外卡包奖励

📦 连胜奖励

连续每日挑战 3/7/14/30 天，分别解锁限定卡牌/头像框/称号

🔗 三模式如何打通

👑 PVP → PVE

爬塔中获得的限定卡牌可以用于PVP。远征通关奖励是竞技场新牌。

🗡️ PVE → 学习

爬塔遇到的生词会被加入"错词本"，下次练习优先复习。远征也是复习。

📚 学习 → PVP+PVE

练听写产出卡包，卡牌组卡组。练得越多，牌越多，对战胜率越高。

🏆 赛季大满贯

每月：PVP天梯排位 + 远征最高层数 + 每日挑战高分 → 三项综合评选"月之王者"
