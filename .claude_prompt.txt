## 项目背景

## 任务一：移除老远征系统代码

ExpeditionPage.tsx 中同时存在"老战斗系统"和"新战斗系统"（BattlePageSit.tsx）两套代码。需要清理：

1. **移除 `showNewCombat` 状态**（第119行）和所有相关引用
   - 只保留 BattlePageSit 的战斗方式
   - 战斗入口统一走 BattlePageSit

2. **移除老战斗函数**：
   - `enterCombat()`（第193~202行）— 老版本进入战斗
   - `handlePlayCard()`（第205~299行）— 老版本手动出牌+动画逻辑
   - 老战斗渲染区域——当 phase === 'combat' 时渲染的老UI代码

3. **清理老数据字段**：
   - `questionsAnswered`、`questionsTotal` 从 ExpeditionData 接口移除
   - settlement 结算函数中的 `exp.questionsAnswered / exp.questionsTotal` 改为使用 `exp.enemiesKilled`

4. **清理老战斗API调用**：
   - `/api/expedition/play-card`（老版出牌接口）
   - `/api/expedition/enter-combat`（老版进入战斗）
   - 这些接口在后端的 ExpeditionService 中保留（其他地方可能用到），前端不再调用即可

5. **清理 `ExpeditionPage.tsx` 中老战斗相关的 effect/animation 引用**：playCardAnimation, elementFlash, showDamageNumber, hitAnimation, screenShake, spawnParticles, victoryEffect, defeatEffect, enemyDeathAnimation, cardDrawAnimation — 这些在清理后如果其他地方（如新战斗）也用了，保留导入；只移除老战斗代码中那些调用。

6. **移除 `ExpeditionPage.tsx.tail` 文件**（已标记删除但可能残留）

**关键原则**：只动 ExpeditionPage.tsx，不动 BattlePageSit.tsx（Task 2会改它）

## 任务三：修复卡片乱码问题

**问题**：用户在手机端看到有些卡片显示乱码（可能是UTF-8编码问题）。

需要检查的地方：
1. **V18/V20/V27/V29 卡牌 seed 数据** — 检查 `effect_json` 中的中文是否正常，特别是 `description_cn` 字段
2. **CardCollectionPage.tsx** — 卡片渲染时是否正确解析了 JSON 中的中文
3. **BattlePage.tsx** — 对战页面的卡片显示
4. **DeckBuilderPage.tsx** — 卡组构建页面的卡片名称
5. **BattleArenaPage.tsx** — 实时对战页面卡片显示

具体操作：
1. 查找前端卡片渲染组件中所有显示 `name_cn` / `nameEn` / `nameCn` 的地方，确认优先使用中文名
2. 查找 `effect_json` 的解析逻辑，确认 `description_cn` 被正确提取并显示，而不是显示 `description_en`
3. 确认所有中文内容在数据库中是正确的 UTF-8 编码
4. 如果发现具体乱码位置，修复编码问题

**注意**：如果实在找不到具体乱码位置，就全面检查并确保：
- 所有卡片优先显示中文名（name_cn）而不是英文名（name_en）
- 所有卡片效果优先显示中文描述（effect_json.description_cn）而不是英文描述
- 前端所有卡片展示组件统一使用中文
