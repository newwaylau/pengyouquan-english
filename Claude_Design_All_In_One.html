📐 设计哲学

🔄

零付费闭环

英语练习 = 唯一资源入口。没有体力系统、没有付费加速、没有等待计时器。练多少拿多少。

🎮

纯策略对战

对战过程零英语题、零打字。炉石式点击操作：点手牌→拖战场→攻击选择。游戏体验与英语完全解耦。

🏗️

渐进式实现

P1：异步挑战（纯REST）→ P2：WebSocket实时对战 → P3：公会/部落战/赛季生态。每阶段可玩。

🃏

收藏驱动

全卡收集、全英雄解锁、全关键词组合。每个扩展包=新卡+新流派+新英雄。持续更新的动力。

🤝

社交粘性

好友挑战、公会归属、段位竞争、部落战集体目标。社交压力+集体荣誉=长期留存。

📊

数据驱动

胜率统计、段位分布、工会贡献、赛季排行。每场对战后有详细复盘。玩家看到进步。

🔌 杀戮尖塔兼容性分析

表结构检查

列名当前值杀戮尖塔需求兼容？
card_typeminion/spell/equipment/locationattack/skill/power/curse/status⚠️ 需映射
cost1-80-3 energy✅
attack0-8damage per card✅
health1-8不适用（HP是战斗状态）✅
effect_jsonJSON描述结构化效果数据⚠️ 需新增字段
keywordsbattlecry/taunt等无直接对应✅
factionstark/targaryen种族faction✅
race龙/人/兽无直接对应✅
element火/冰/暗影无直接对应✅

卡牌类型映射

minion → attack（造成伤害的随从卡）
       → skill（提供格挡/效果的随从卡）
spell  → skill（法术效果）
       → power（持续能力）
equipment → power（装备效果）
location → power（场地效果）

效果数据结构化要求

当前 effect_json 是自由文本描述，StS需要结构化字段：

{
  "damage": 6,
  "block": 5,
  "buff_self": {"strength": 1},
  "debuff_enemy": {"vulnerable": 2},
  "draw": 1,
  "description_cn": "造成 6 点伤害，获得 5 点格挡"
}

结论

✅ 数据结构完全兼容

race/element/keywords/rarity 字段都已存在

✅ 可直接用现有卡牌

只需添加 effect_structured 字段

⚠️ 缺少StS战斗数据

需要为每张卡补充 damage/block/buff 参数

🔄 核心循环（Core Loop）

登陆 → 练习英语（听写/填空/翻译）→ 得星尘
  → 星尘合成卡包 → 开包得新卡（进入永久收藏池）
  → 进入远征 → 从收藏池选8-10张初始牌组
  → 跑图10幕520节点岔路 → 战斗/精英/事件/篝火/商店/宝箱/Boss
  → 通关或死亡 → 得金币+星尘奖励
  → 用金币买更多卡包 → 收藏更大 → 下次远征更强

远征内战斗为纯杀戮尖塔模式：每回合3能量、摸5张牌、出牌攻击敌人、看敌人意图、策略选择。英语只在外围（练习→得资源），远征内无任何题目打断。

⚔️ 战斗系统

回合流程

[每回合开始]
  1. 摸5张牌 → 获得3能量
  2. 玩家出牌阶段（可出任意数量牌，直到能量耗尽或手牌打完）
  3. 点击「结束回合」
  4. 弃掉所有手牌（剩余手牌→弃牌堆）
  5. 敌人行动（执行其意图，攻击/上Buff/Buff等）
  6. 回合结束 → 回到步骤1

状态效果

状态类型效果
⚔️ 力量 (Strength)Buff每点+1攻击伤害
🛡️ 敏捷 (Dexterity)Buff每点+1格挡值
🔴 易伤 (Vulnerable)Debuff受到伤害+50%
🔵 虚弱 (Weak)Debuff造成伤害-25%
🟤 脆弱 (Frail)Debuff获得格挡-25%
🟢 中毒 (Poison)Debuff回合开始扣(层数)血，层数-1
🟡 缠绕 (Slow)Debuff每打一张牌敌人受伤害+10%
❄️ 冰冻 (Frost)Debuff攻击前消耗1层，攻击力-3
☠️ 标记 (Marked)Debuff下一攻击命中时额外+50%伤害
🛡️ 格挡 (Block)临时护甲回合结束消失

伤害计算公式

最终伤害 = 基础伤害 + 力量加成
如果敌人有易伤(Vulnerable)：最终伤害 × 1.5   (每层+50%)
如果玩家有虚弱(Weak)：最终伤害 × 0.75
如果敌人有缠绕(Slow)：回合内每张牌+10%
如果敌人有标记(Marked)：第一次命中×1.5

最终伤害 ≥ 1（至少1点伤害）

-- 卡牌数据
CREATE TABLE cards (
  id BIGINT AUTO_INCREMENT PRIMARY KEY,
  card_name VARCHAR(100) NOT NULL,
  card_name_en VARCHAR(100),
  card_type ENUM('attack','skill','power','curse','status') NOT NULL,
  rarity ENUM('basic','common','uncommon','rare') NOT NULL DEFAULT 'common',
  cost INT NOT NULL DEFAULT 1,
  description TEXT NOT NULL,
  base_damage INT DEFAULT 0,
  base_block INT DEFAULT 0,
  keywords JSON,
  upgrade_description TEXT,
  upgrade_damage INT DEFAULT 0,
  upgrade_block INT DEFAULT 0,
  is_x_cost BOOLEAN DEFAULT FALSE,
  show_id BIGINT,
  created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
