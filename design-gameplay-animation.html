1完整回合流程时序图

每个回合严格遵循 开始 → 抽牌 → 法力增长 → 主阶段 → 战斗阶段 → 结束 的六阶段流水线。以下时序图展示玩家（P1）与对手（P2）在一个完整回合中的交互序列。

玩家 P1 对手 P2
T+0s
🟢 阶段 1 — 回合开始 (Begin Turn)
后端发送 onTurnStart 事件，包含 turnNumber、mana、maxMana。前端调用 EffectEngine.victoryEffect/defeatEffect 终止上一回合残留。设置 isMyTurn = true，启动 60s 倒计时。
BattleWebSocket → onTurnStart({ turnNumber, mana, maxMana, hand })

后端自动抽牌，onGameState 推送新 myHand。前端调用 EffectEngine.cardDrawAnimation(container, handArea, '🃏')：卡片从牌堆右上角飞入手牌区左侧，耗时 350ms。期间 动画锁定（isAnimating = true），玩家不可操作。

T+0.8s
🟣 阶段 3 — 法力增长 (Mana Growth)
maxMana++，myMana = maxMana。法力水晶 UI 使用 @keyframes mana-grow 缩放动画（0.3s cubic-bezier）。若费用不足的卡牌变为可出，触发 playable CSS 类切换 + 微光动效。P2 端同步更新法力显示。
battle-arena-mana-text { transition: color 0.3s, transform 0.3s; }
T+1.2s
🟡 阶段 4 — 主阶段 (Main Phase)
玩家可执行：出牌（点击手牌 → handlePlayCard → playCardAnimation → WS playCard）、使用英雄技能（heroPowerEffect）、装备武器（TODO: 武器系统）。每次操作触发对应动画 + 状态乐观更新。主阶段无时间限制（受 60s 总回合限制）。
await playCardAnimation(cardEl, container, style.color) → ws.playCard(sessionId, cardId)
T+n
🔴 阶段 5 — 战斗阶段 (Combat Phase)
玩家选择攻击方（handleSelectAttacker → attackMode = true）→ 选择目标 → handleAttackTarget → minionChargeAnimation(attackerEl, damage) → WS attack。后端返回 onAttackResult：showDamageNumber + hitAnimation + screenShake + whiteFlash（大伤害）。
minionChargeAnimation → showDamageNumber → hitAnimation → screenShake
T+end
⚫ 阶段 6 — 结束阶段 (End Turn)
玩家点击"结束回合"→ handleEndTurn → WS endTurn → isMyTurn = false。对手端收到 onOpponentTurn → 切换为己方回合。若倒计时归零自动触发 endTurn。游戏结束触发 onGameOver → victoryEffect / defeatEffect。
ws.endTurn() → setState({ isMyTurn: false }) → stopTurnTimer()
设计要点： 每个阶段之间使用 await 保证动画串行播放；BattleArenaPage.tsx 的 handlePlayCard 先 await playCardAnimation 再发送 WS 消息，确保"先看到飞出，再收到服务端确认"。

2奥秘触发系统

2.1 后端状态机设计

奥秘（Secrets）在后端以有限状态机（FSM）实现，定义在 backend/ 的 SecretEngine 模块中。每个奥秘卡牌实例化一个状态机实例。

🔮
IDLE
奥秘挂载，未触发
⚡ 事件触发条件满足
❓
TRIGGERING
判断合法性，通知前端
✅ 有效触发
💥
ACTIVATED
执行效果 + 动画
⏳ 效果结束
💀
CONSUMED
奥秘消耗，从战场移除
// 奥秘状态机 — 伪代码（backend/SecretEngine.ts）
  enum SecretState {
    IDLE,         // 奥秘挂载在英雄头像上
    TRIGGERING,   // 条件满足，进入触发判定
    ACTIVATED,    // 触发成功，执行效果
    CONSUMED      // 消耗，移除
  }

  interface SecretInstance {
    cardId: number;
    ownerId: number;
    state: SecretState;
    condition: SecretCondition; // 触发条件函数
    effect: SecretEffect;           // 触发后效果
  }

  class SecretEngine {
    secrets: Map<number, SecretInstance>;

    registerSecret(cardId: number, ownerId: number, config: SecretConfig): void;

    // 每当游戏事件发生，检查是否满足某个奥秘的触发条件
    onGameEvent(event: GameEvent): SecretInstance | null {
      for (const secret of this.secrets.values()) {
        if (secret.state !== SecretState.IDLE) continue;
        if (secret.condition(event)) {
          secret.state = SecretState.TRIGGERING;
          return secret;
        }
      }
      return null;
    }

    // 确认触发 → 执行效果并消耗
    confirmTrigger(secret: SecretInstance): SecretEffectResult {
      secret.state = SecretState.ACTIVATED;
      const result = secret.effect.execute();
      secret.state = SecretState.CONSUMED;
      this.secrets.delete(secret.cardId);
      return result;
    }
  }

// 武器系统 — 伪代码（frontend/src/WeaponEngine.ts 提案）
  interface WeaponState {
    cardId: number;
    name: string;
    attack: number;
    baseAttack: number;
    durability: number;
    maxDurability: number;
    elementType?: string;
  }

  // 在 BattleArenaPage.tsx 中扩展的状态
  interface BattleState {
    // ... 现有字段
    myWeapon: WeaponState | null;
    opponentWeapon: WeaponState | null;
    weaponAttackMode: boolean;  // 武器攻击模式
  }

  // 武器攻击处理
  const handleWeaponAttack = async (targetType: string, targetId?: number) => {
    if (!state.myWeapon || state.myWeapon.durability <= 0) return;

    // 武器冲锋动画（复用 minionChargeAnimation）
    const weaponEl = weaponRef.current;
    if (weaponEl) {
      await minionChargeAnimation(weaponEl, state.myWeapon.attack);
    }

    // 发送 WS 消息
    ws.weaponAttack(sessionId, targetType, targetId);

    // 乐观更新耐久度
    setState(prev => ({
      ...prev,
      myWeapon: prev.myWeapon
        ? { ...prev.myWeapon, durability: prev.myWeapon.durability - 1 }
        : null,
    }));
  };

  // 武器摧毁动画
  const handleWeaponDestroyed = useCallback((el: HTMLElement) => {
    // 白色闪屏
    whiteFlash(el);
    // 碎裂粒子 (metal 风格)
    spawnParticles(el, el.offsetWidth / 2, el.offsetHeight / 2, 20, 'metal');
    // 收缩消失
    el.style.transition = 'all 0.3s ease-out';
    el.style.transform = 'scale(0)';
    el.style.opacity = '0';
    setTimeout(() => { el.remove(); }, 350);
  }, []);
集成路径： 武器系统扩展 BattleArenaPage.tsx 的 BattleState 接口，新增 myWeapon/opponentWeapon 字段。WS 消息类型增加 weapon_equip、weapon_attack、weapon_destroyed。

5卡牌入场动画与游戏状态同步

5.1 时序模型

卡牌出场到场上生效的完整时序分为三个阶段：

阶段 A — 动画前（锁定操作）
① 玩家点击手牌 → handlePlayCard(card) 被调用
② isAnimating = true → 所有操作按钮 disabled
③ playCardAnimation(cardEl, container, color) 开始播放
④ 克隆卡牌从手牌位置飞向战场中心（0.3s 飞行 + 0.25s 收缩）
阶段 B — 动画结束 + WS 发送（乐观更新）
⑤ await playCardAnimation(...) 完成 → isAnimating = false
⑥ 乐观更新：从 myHand 移除该卡，扣除 myMana
⑦ ws.playCard(sessionId, card.cardId) 发送到服务端
⑧ 操作恢复（但资源已扣，防止重复操作）
阶段 C — 服务端确认 + 落地特效
⑨ 收到 onCardPlayResult 回调
⑩ elementFlash(container, config.element) — 元素闪屏
⑪ spawnParticles(container, cx, cy, config.particleCount, config.element) — 粒子爆发
⑫ onGameState 推送最新完整状态 → 随从出现在 myBoard

5.2 动画锁定机制

// 动画锁定实现 — BattleArenaPage.tsx
  const [isAnimating, setIsAnimating] = useState<boolean>(false);
  const animQueueRef = useRef<Array<() => Promise<void>>>([]);
  const isProcessingRef = useRef<boolean>(false);

  // 动画队列处理器
  const processAnimQueue = useCallback(async () => {
    if (isProcessingRef.current) return;
    isProcessingRef.current = true;
    setIsAnimating(true);

    while (animQueueRef.current.length > 0) {
      const nextAnim = animQueueRef.current.shift();
      if (nextAnim) {
        await nextAnim();
      }
    }

    isProcessingRef.current = false;
    setIsAnimating(false);
  }, []);

  // 入队
  const enqueueAnimation = useCallback((animFn: () => Promise<void>) => {
    animQueueRef.current.push(animFn);
    processAnimQueue();
  }, [processAnimQueue]);

  // 使用 — 在 handlePlayCard 中
  const handlePlayCard = async (card: CardData) => {
    if (!state.isMyTurn || isAnimating || state.attackMode) return;
    if (card.cost > state.myMana) return;

    enqueueAnimation(async () => {
      const cardEl = handCardRefs.current.get(card.cardId);
      const container = fieldRef.current;
      if (cardEl && container) {
        const config = getCardAnimConfig(card.attack, card.rarity);
        const style = ELEMENT_STYLES[config.element] || ELEMENT_STYLES.fire;
        await playCardAnimation(cardEl, container, style.color);
      }
      ws.playCard(state.sessionId, card.cardId);
      setState(prev => ({
        ...prev,
        myHand: prev.myHand.filter(c => c.cardId !== card.cardId),
        myMana: prev.myMana - card.cost,
      }));
    });
  };

5.3 队列系统设计

当多个动画需要串行播放时（如连续出牌或连锁效果），使用 FIFO 队列 + Promise 链：

特性 说明
队列结构useRef<Array<() => Promise<void>>>([]) — 函数引用数组
处理器processAnimQueue — 递归消费队列，isProcessingRef 防止并发
锁定标志isAnimating — 状态值，控制 UI 组件 disabled
入队时机用户操作时 enqueueAnimation，WS 回调也入队
队列容量理论无上限，但单回合操作不超过 10 次
中断条件回合结束 / 游戏结束 → animQueueRef.current = []
超时保护单个动画超过 5s → 自动跳过并 resolve（防止死锁）
 
// 带超时保护的动画包装器
  function withTimeout<T>(promise: Promise<T>, ms: number = 5000): Promise<T | void> {
    return Promise.race([
      promise,
      new Promise<void>(resolve => setTimeout(resolve, ms)),
    ]);
  }

  // 使用包装
  enqueueAnimation(async () => {
    await withTimeout(playCardAnimation(cardEl, container, style.color));
    // 继续执行...
  });

6EffectEngine 改造方案

6.1 当前架构分析

现有两套独立的动画引擎：

引擎文件路径技术实现特点
EffectEngine (DOM) frontend/src/EffectEngine.ts 纯 DOM 操作，创建 div/span，CSS transition + animation 轻量、易于调试、与 React DOM 紧密耦合
EffectEngine (Canvas) frontend/src/effects/EffectEngine.ts Canvas 2D + requestAnimationFrame 循环 高性能粒子系统，延迟渲染，适合大量粒子
AnimProfileBuilder (旧) frontend/src/AnimProfileBuilder.ts 简单配置表，通过 getCardAnimConfig(attack, rarity) 返回颜色/粒子数 接口简洁，但功能有限
AnimProfileBuilder (新) frontend/src/effects/AnimProfileBuilder.ts buildProfile(card: CardResponse) 返回完整 AnimProfile 对象 包含入场类型、元素覆盖层、关键词、稀有度等全维度配置

6.2 集成方案

将两套引擎统一为一个 AnimationManager 单例，对外暴露统一 API：

// === AnimationManager — 统一动画管理器（提案）===
  // 文件路径：frontend/src/AnimationManager.ts

  import { playCardAnimation, elementFlash, showDamageNumber, hitAnimation,
           screenShake, spawnParticles, whiteFlash, minionChargeAnimation,
           heroPowerEffect, cardDrawAnimation, enemyDeathAnimation }
    from './EffectEngine';  // DOM 版

  import { ParticleManager, type ParticleStyle }
    from './effects/EffectEngine';  // Canvas 版

  import { buildProfile, type AnimProfile }
    from './effects/AnimProfileBuilder';

  import { injectCardAnimations, ALL_ANIMATIONS }
    from './effects/CardAnimations';

  // ========== 统一接口 ==========

  export class AnimationManager {
    private static instance: AnimationManager;
    private particleManager: ParticleManager;
    private profileCache: Map<number, AnimProfile>;
    private containerRef: HTMLElement | null = null;

    static getInstance(): AnimationManager {
      if (!this.instance) {
        this.instance = new AnimationManager();
      }
      return this.instance;
    }

    /** 初始化: 注入CSS + 挂载Canvas + 设置容器引用 */
    init(container: HTMLElement, canvas: HTMLCanvasElement): void {
      this.containerRef = container;
      injectCardAnimations();  // 注入 CSS keyframes
      this.particleManager = new ParticleManager();
      this.particleManager.mount(canvas);
      this.particleManager.start();
      this.profileCache = new Map();
    }

    /** 销毁清理 */
    destroy(): void {
      this.particleManager.unmount();
      this.containerRef = null;
      this.profileCache.clear();
    }

    /** 根据 CardResponse 构建并缓存 AnimProfile */
    getProfile(card: CardResponse): AnimProfile {
      const cached = this.profileCache.get(card.cardId);
      if (cached) return cached;
      const profile = buildProfile(card);
      this.profileCache.set(card.cardId, profile);
      return profile;
    }

    /** 播放卡牌入场动画 (DOM飞入 + Canvas粒子) */
    async playCardEntry(
      cardEl: HTMLElement,
      card: CardResponse,
      color: string
    ): Promise<void> {
      const container = this.containerRef;
      if (!container) return;

      // 1. DOM 飞入动画
      await playCardAnimation(cardEl, container, color);

      // 2. Canvas 粒子爆发 (根据 AnimProfile)
      const profile = this.getProfile(card);
      const cx = container.offsetWidth / 2;
      const cy = container.offsetHeight / 2;
      this.particleManager.burstEffect(cx, cy, profile.particleCount, profile.particleStyle);

      // 3. 元素闪屏
      const style = ELEMENT_STYLES[profile.particleStyle] || ELEMENT_STYLES.fire;
      elementFlash(container, style.flashClass);
    }

    /** 播放攻击动画链 */
    async playAttackChain(
      attackerEl: HTMLElement,
      targetEl: HTMLElement | null,
      damage: number,
      dmgColor: string,
      targetX: number,
      targetY: number
    ): Promise<void> {
      const container = this.containerRef;
      if (!container) return;

      // 1. 攻击方冲锋动画
      await minionChargeAnimation(attackerEl, damage);

      // 2. 受击方后仰 (并行)
      if (targetEl) {
        hitAnimation(targetEl, damage >= 8 ? 'big' : damage >= 5 ? 'mid' : 'light');
      }

      // 3. 伤害数字 (并行)
      showDamageNumber(container, targetX, targetY, damage, dmgColor);

      // 4. 屏幕震动 (并行)
      screenShake(container, damage);

      // 5. 大伤害白闪 (并行)
      if (damage >= 8) {
        whiteFlash(container);
      }

      // 6. Canvas 粒子 (并行)
      this.particleManager.burstEffect(targetX, targetY, 10, 'fire');
    }

    /** 通用动画播放: 根据事件类型自动调度 */
    async dispatchEvent(event: AnimationEvent): Promise<void> {
      switch (event.type) {
        case 'card_play':
          return this.playCardEntry(event.cardEl!, event.card!, event.color!);
        case 'attack':
          return this.playAttackChain(
            event.attackerEl!, event.targetEl!,
            event.damage!, event.dmgColor!,
            event.targetX!, event.targetY!
          );
        case 'hero_power':
          heroPowerEffect(this.containerRef!, event.elementType!);
          break;
        case 'card_draw':
          await cardDrawAnimation(this.containerRef!, event.handArea!, '🃏');
          break;
        case 'victory':
          await victoryEffect(this.containerRef!);
          break;
        case 'defeat':
          await defeatEffect(this.containerRef!);
          break;
      }
    }
  }

  // ========== 在 BattleArenaPage.tsx 中使用 ==========
  const animManager = useRef<AnimationManager>(new AnimationManager());

  useEffect(() => {
    const container = fieldRef.current;
    const canvas = canvasRef.current;
    if (container && canvas) {
      animManager.current.init(container, canvas);
    }
    return () => animManager.current.destroy();
  }, []);

// 统一调度入口 — AnimationManager.dispatchEvent 实现骨架
  async dispatchEvent(event: AnimationEvent): Promise<void> {
    const container = this.containerRef;
    if (!container) return;

    this.animQueueRef.push(async () => {
      switch (event.type) {
        case 'turn_start': {
          if (event.cardContent) {
            await withTimeout(cardDrawAnimation(container, event.handArea!, event.cardContent));
          }
          // mana grow CSS
          const manaEl = container.querySelector('.battle-arena-mana-text');
          if (manaEl) {
            (manaEl as HTMLElement).style.animation = 'mana-grow 0.3s ease-out';
            setTimeout(() => { (manaEl as HTMLElement).style.animation = ''; }, 300);
          }
          break;
        }

        case 'card_play': {
          await this.playCardEntry(event.cardEl!, event.card!, event.color!);

          // 播放 AnimProfile 中的关键词/稀有度动画
          if (event.card) {
            const profile = this.getProfile(event.card);
            profile.kwAnim.forEach(kw => event.cardEl!.style.animation += ` ${kw} ${profile.duration}s ease-out`);
            if (profile.rarityGlow) {
              event.cardEl!.classList.add(profile.rarityGlow);
            }
          }
          break;
        }

        case 'attack': {
          await this.playAttackChain(
            event.attackerEl!, event.targetEl!,
            event.damage!, event.dmgColor!,
            event.targetX!, event.targetY!
          );
          break;
        }

        case 'secret_triggered': {
          elementFlash(container, 'light');
          spawnParticles(container, container.offsetWidth / 2, container.offsetHeight / 2, 30, 'light');
          const secretEl = container.querySelector('.secret-icon');
          if (secretEl) {
            (secretEl as HTMLElement).style.animation = 'secret-reveal 0.6s ease-out forwards';
            setTimeout(() => secretEl.remove(), 700);
          }
          break;
        }

        case 'victory': {
          await victoryEffect(container);
          break;
        }
        case 'defeat': {
          await defeatEffect(container);
          break;
        }
      }
    });

    await this.processAnimQueue();
  }
