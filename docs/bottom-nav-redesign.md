# 底部导航栏重新设计方案

## 1. 按钮布局与架构

### 新版导航栏（5个按钮）

```
┌──────────────────────────────────────────────────────────┐
│  📖学习    ❌错题    ⚙️设置    🔍搜索    🧘专注            │
│  (跳页)    (跳页)    (弹窗)    (面板)    (切换)           │
└──────────────────────────────────────────────────────────┘
```

### 每个按钮的点击行为

| 按钮   | 当前                                     | 改造后                                                    |
|--------|------------------------------------------|-----------------------------------------------------------|
| 📖学习 | disabled 🚧                              | 点击切换到 BrowsePage（剧集学习入口）                         |
| ❌错题 | 跳到 WrongPage（简单列表）                  | 跳到 WrongPage（复习看板+排序+练习入口）                     |
| ⚙️设置 | 弹窗 SettingsPanel                         | 不变（保持弹窗式）                                         |
| 🔍搜索 | disabled 🚧                              | 点击弹出搜索面板/内嵌搜索框（与浏览融合）                    |
| 🧘专注 | 切换 focusMode 状态                         | 不变                                                     |

### 交互方式决策

- **保留底部导航条** — 5按钮 tab 式布局，通过 `onNavigate` 切换主页面
- 浏览/错题/搜索为**全页切换**，设置为**弹窗**，专注为**状态切换**
- 所有按钮均激活，不再有"建设中"占位

## 2. 各个功能模块详细规格

### 2.1 📖浏览功能重构（改造为"剧集学习入口"）

- 去掉句子ID跳转输入框
- 剧集选择改造为三级目录：**剧集→季→集**
- 每集显示：标题 + 句子数
- 内嵌搜索框（按关键字搜索当前剧集句子）
- 默认按热度（练习次数/错误次数）排序
- 点击某句子 → 跳转到 PracticePage 练习

### 2.2 ❌错题功能改造（复习看板）

**Phase 1（本阶段实现）：**
- 列表排序改为：按**错误次数**降序 + 按**最近练习时间**倒序
- 显示每个句子的详细统计：错误次数、练习次数、最后练习时间
- 加入"错题练习模式"按钮 → 只从错题中随机抽取句子练习
- 练完后显示"再练一遍"按钮
- 统计卡片显示：总错题数 + 高频错题TOP 3

**Phase 2（下一阶段）：**
- SM-2 间隔复习算法

### 2.3 ⚙️设置

- 保持弹窗式 SettingsPanel
- 后续可考虑增加更多设置项

### 2.4 🔍搜索

- 从"建设中"激活
- 点击弹出浮动搜索面板（不跳页）
- 支持中英文搜索
- 搜索结果允许一键练习
- 后续考虑与浏览页面内嵌搜索合并

### 2.5 🧘专注

- 保持现有功能不变

## 3. 技术方案

### 3.1 前端改动文件清单

| 文件                         | 改动内容                                                       |
|------------------------------|---------------------------------------------------------------|
| `App.tsx`                    | 路由重构（添加 episode 学习入口路由）、登录拦截重构              |
| `PracticePage.tsx`           | 底部导航按钮 onClick 更新（移除 disabled）                      |
| `BrowsePage.tsx`             | 改造成剧集三级学习入口                                         |
| `WrongPage.tsx`              | 改造成复习看板（排序、统计、练习模式入口）                      |
| `SearchPage.tsx`             | 从独立页面改造为浮动面板                                       |
| `index.css`                  | 新增搜索面板样式、WrongPage 统计卡片样式等                      |

### 3.2 后端改动接口清单

| 接口路径                     | 改动内容                                                       |
|------------------------------|---------------------------------------------------------------|
| `GET /api/wrong-sentences`   | 新增排序参数（orderBy=errorCount/practicedAt）                  |
| `GET /api/wrong-sentences/stats` | （新增）统计接口：高频错题TOP 3等                           |
| `GET /api/wrong-practice`    | （新增）错题练习接口：从错题本中随机抽取句子                    |

### 3.3 数据库表结构

当前 `wrong_sentences` 表已有字段：
- `id`, `user_id`, `sentence_id`, `error_count`, `last_practiced_at`, `created_at`

**无需新增表**，现有字段足以支持 Phase 1 的错题复习排序。

### 3.4 状态管理方案

- 当前使用 React 组件本地状态 + `onNavigate` 回调进行页面切换
- 底部导航栏状态由 `PracticePage` 管理
- 路由由 `App.tsx` 统一管理
- **保持现有方案**，不引入 Redux 等外部状态管理
- 搜索面板状态使用 `PracticePage` 的本地 state
